# 02 — Regulation Q&A (planned)

**Problem.** Restaurant owners get "can I do X?" answers from Google and hearsay. FDA,
Indiana and county rules don't always agree, and a confident wrong answer can fail an inspection.

**This project** answers only from downloaded source text (Indiana retail food rule, the FDA
Food Code edition Indiana adopted, Vanderburgh County requirements, selected Indiana ABC,
youth-employment and IRS tip rules), cites the section for every claim, applies the right
level of government, and says "not covered" when the documents don't answer it.
Informational only — not legal advice.
